## 功能包：代理模板 / 负载均衡 / 实时指标 / 访问日志 / diff 体系

### 新增功能

- **代理场景模板**：添加代理可选 standard / websocket / sse / upload 四种模板，自动追加对应指令（WS：`proxy_http_version 1.1` + Upgrade 头 + 300s 读超时；SSE：`proxy_buffering off` 等；上传：`client_max_body_size 1024m` 等）；已有代理按块内特征指令反向嗅探并展示模板标签。
- **upstream 负载均衡**：可视化新建/编辑 upstream（round_robin / least_conn / ip_hash，支持 weight/backup/down，extra 参数原样保留）；代理目标填 `http://名称` 即接入（目标输入框带 datalist 联想）；被代理引用时删除会被拒绝。
- **实时连接指标**：自动检测 stub_status 状态页并在状态栏展示活跃连接与请求速率（两次采样差值）；未配置时一键开启（仅允许 127.0.0.1 访问，走备份 + `nginx -t` 校验流水线）。
- **访问日志查看**：解析 access_log 指令定位日志文件，有界读取尾部 500 行，前端本地关键字过滤；错误日志同样支持查看。
- **diff 体系**：保存前本地行级 diff 预览（超大改动自动退化整体替换）；`nginx -t` 校验失败解析出错文件与行号（errFile/errLine），编辑器一键跳行；备份任意两版本 unified diff 对比。
