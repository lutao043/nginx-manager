## 界面整体重构：更清晰、更克制、更好用

这一版把前端界面从头重写了一遍。功能与接口完全不变（**无契约变更**，`API.md` 无需改动），改的是「看得清、点得准」这件事本身。

### 视觉与信息层级

- **用边框和表面色阶界定层级**，去掉了阴影、光晕、渐变和玻璃拟态——对齐 Linear / Vercel / Supabase 一类开发者控制台的语言，界面更安静、更耐看。
- **强调色回归语义**：绿色只留给「当前状态」和主操作，其余一律走中性描边。场景模板标签改为中性，破坏性操作（删除代理 / 删除 upstream）统一为危险色。
- **8 套主题**：翡翠 / 海洋 / 琥珀 / 玫红，各带日夜两版，全部走 CSS 变量。主题改为**色板弹层**选择——主题是"看着选"的，色块比文字列表更快辨认，并记住你的选择。
- 图标全部改为**内联 SVG**（10 枚，随代码内联，零外部请求），替掉原先的字符符号，小尺寸下更清晰。

### 可读性与可达性修正

- 暗色下最浅一档灰字对比度只有约 **2.9:1**（示例路径、提示文字基本看不清），重排中性色阶后提升到 **4.5:1**；亮色主题同步收敛。
- 翡翠亮色主题的实心绿色按钮白字对比度 **4.1:1 → 5.0:1**。
- 输入框占位符改用更亮一档灰，暗色下不再「看不见示例」。
- **禁用按钮改成描边灰底**，一眼能看出「不可点」，而不是只降低一点透明度。
- 同一行的下拉框、搜索框与迷你按钮**统一高度**，动作行不再上下参差。

### 使用提示

- Windows：下载 `nginx-manager-v0.7.0.exe` 替换旧版即可。旧进程仍在运行时，直接启动新 exe 会由单实例机制自动接管旧实例。
- 前端资源持久化目录随版本号变化（`…\nginx-manager\frontend\v0.7.0\`），升级后自动使用新界面，无需清理缓存。
- 源码运行：刷新页面即可看到新界面。
