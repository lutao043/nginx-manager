## 1.0.0：正式版

这是 **1.0.0 正式版**——从 0.1.1 一路走到这里，功能、可达性与可靠性三方面都按「敢推荐给不用命令行的人」这条线验收过了：改配置不会失手、失手能立刻退回、键盘和读屏都能走完流程。

如果你之前用的是候选版（rc.1 / rc.2），直接升到这一版即可，全部内容都包含在内。

### 这一版相对候选版的变化

**更快、更省资源**

- 空闲时不再反复重读与重扫 nginx 配置：开着页面挂一天，CPU 占用明显更省（配置没变就不重复解析）。
- 日志面板改为「只追加」：长日志持续写入时不再整段重排，滚动更跟手、内存占用更平稳。
- 页面刷新走条件请求、连接复用：重复打开页面不再整份重传约 200KB 的前端资源。

**修掉的问题**

- macOS 上手工启动的 nginx 有时被显示成「未运行」，连重启/重载也会被拒绝，点「启动」还可能把正在运行的实例搞乱——现在能认准。
- 状态页（stub_status）在配置里写成一行时，实时指标一直显示「未开启」——现在单行与多行写法都认。
- 日志为空时打开日志面板，之后新日志前面会粘着一句「（错误日志为空或文件不存在）」——已修。
- 用启动参数指定 nginx 路径与配置目录时，界面仍要求重新填写路径——现在直接进入主界面。
- 状态页已经存在时点「开启状态页」，会提示「配置已写入并通过校验」（其实什么都没改）——现在如实提示「已存在，未做改动」。
- 现在支持 `HEAD` 请求（`curl -I` 可以正常探活）。

### 候选版里已经交付、正式版同样包含的内容

- **日志实时跟随与暂停**：错误日志 / 访问日志自动滚动，随时可暂停；暂停期间新日志照常累积并提示未读行数，阅读位置不被打断。
- **编辑器行号与撤销重做**：行号栏随滚动同步；校验失败可一键跳到出错行；Ctrl/Cmd+Z 撤销、Ctrl+Y 重做。
- **键盘与读屏可达**：弹窗焦点陷阱、Esc 关闭、页签方向键切换、结果用读屏播报。
- **页面版本号与更新历史**：顶栏常显版本号，点开可逐版本查看更新说明；说明随程序打包，离线可读。
- **暗夜主题观感调柔**：深色主题点字亮度降了一档，长时间看着不累，可读性不变。

### 升级方式

- Windows：下载 `nginx-manager-v1.0.0.exe` 替换旧 exe 即可。旧进程仍在运行时，直接启动新 exe 会由单实例机制接管。
- 前端资源按版本持久化（`…\nginx-manager\frontend\v1.0.0\`），升级后自动使用新界面，无需清理缓存。
- 源码运行：拉取后重启服务，刷新页面即可。
- 再说一次：**本程序不做自动更新**——不联网检查版本、不自动下载、也不会偷偷替换自己。你的设置与备份都在数据目录里，换 exe 后照旧可用。

### 请你重点试试

- 顶栏的版本号是否和你下载的 exe 对得上；点开「更新历史」能否正常看到各版本说明。
- 日志自动跟随、暂停后阅读位置是否不被顶走；编辑器行号与撤销重做（Ctrl/Cmd+Z、Ctrl+Y）。
- 保存一份有语法错误的配置，看提示与「一键回滚」是否照常工作。
- Windows 下的首次启动选择框，以及覆盖安装后原来的设置与备份是否照旧可用。

反馈问题时请带上顶栏显示的版本号，方便定位。
