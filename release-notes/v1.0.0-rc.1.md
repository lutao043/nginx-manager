## 1.0.0-rc.1：发布候选版，请到真实环境验收

这是一次**发布候选（release candidate）**，不是正式版。v0.7.0 之后的全部改造都已合入并跑绿了自动化门禁，剩下的最后一道关口是**真实环境验收**——请拿这个版本在你实际的 nginx 与操作系统上跑一遍；通过后将以同一份代码转正为 `v1.0.0`（只提升版本号，代码不动）。

### 新增：日志实时跟随 + 可暂停（本版主打）

- 错误日志与访问日志**自动跟随滚动**，新日志一出现就贴到最新一行，不用再手点刷新。
- **随时暂停/继续**：点暂停，或自己往上滚动，即停止跟随；暂停期间新日志照常累积，并提示「新日志 N 行」，你的阅读位置不会被顶走。
- 访问日志可切换日志文件、按关键字过滤；过滤与跟随互不干扰。
- 实现上按字节偏移增量拉取、只在完整行边界前进，单次有上限并自动续取，长日志与轮转场景都不会漏行或重复。

### 编辑器：行号 + 撤销重做 + 报错定位

- 编辑器左侧**行号栏**随内容与滚动同步。
- **Ctrl/Cmd+Z 撤销、Ctrl+Y 重做**（自建快照历史，连续输入自动合并，不会一步退一个字）。
- `nginx -t` 失败时，从真实报错输出里解析出错文件与行号，**一键跳转并居中高亮该行**。

### 可达性：键盘与读屏可用

- 弹窗**焦点陷阱**开启时背景 `inert`，关闭后焦点回到触发处。
- 页签支持方向键切换（roving tabindex），选中态与 `aria-selected` 跟随。
- Toast 与状态提示通过 `aria-live` 播报；文件树可聚焦、可回车打开；`Esc` 为编辑器提供不依赖 Tab 的焦点出口。

### 质量门禁（v0.7.0 之后新建，现已接入 CI）

- **后端回归测试**：真实服务子进程 + 真实 HTTP（只把 nginx 换成替身脚本），覆盖状态 / 配置树 / 文件读写 / 路径穿越 / CSRF / 校验失败 409 与行号解析 / 备份删除与回滚，含「最坏失败模式」门禁。当前 **117 用例**，`unittest` 与 `pytest` 双入口。
- **DOM 契约检查**：JS 引用的 `#id` 必须存在于页面或由 JS 运行时创建，class 必须在样式表有定义，另查未定义 CSS 变量。
- **契约与版本一致性**：`API.md` 声明的端点与实现双向比对，成功响应顶层字段逐个核对；版本号单一来源（`server_version`）派生校验，且不得落后于最新 tag。
- **对比度审计**：8 套主题的关键配色对按 WCAG AA 核算并作为门禁。
- **真实 nginx 端到端走查**：用真实 nginx 二进制跑启动 / 重载 / 停止、报错行号、代理生效与回滚、指标抓取、日志读取与安全边界，退出码即结论（发布前手动跑）。

### 配置改写与 nginx 控制加固

- 代理 / upstream 改写不再误伤：忽略引号内的花括号，识别单行 `location` / `upstream`，无法安全建模时**明确拒绝**（`409`）而不是静默丢弃手写指令。
- 保留原有 CRLF 行尾；`prefix` 与 pid 按 `nginx -V` 编译参数与 `pid` 指令解析，工作区双布局（`nginx.exe` / `sbin/nginx`）自动识别。
- `--port` 越界或非整数**入口即拒绝**（退出码 2），不再等到 bind 才报错。

### 界面与配色

- 8 套主题的灰字与状态色重排到 WCAG AA 可读档位；禁用态改为描边灰底，一眼可辨。
- 修复窗口偏矮时编辑器卡片把提示条顶出去压住底部停靠区的问题。

### 使用提示

- Windows：下载 `nginx-manager-v1.0.0-rc.1.exe` 替换旧版即可。旧进程仍在运行时，直接启动新 exe 会由单实例机制接管旧实例。
- 前端资源按版本持久化（`…\nginx-manager\frontend\v1.0.0-rc.1\`），升级后自动使用新界面，无需清理缓存。
- 源码运行：刷新页面即可。
- **验收重点建议**：日志跟随/暂停在长日志与轮转下的表现、编辑器行号与撤销、键盘走查（Tab/Esc/方向键）、保存校验失败后的回滚，以及 Windows 下的首次启动选择框。
