## 1.0.0-rc.2：顶栏显示版本号，点开就是更新历史

这是一个**候选版**，还不是正式版：请拿它在你自己真实的 nginx 环境里用一用，没问题才会转正为 1.0.0。

### 新增：页面上直接看到版本号，随时可查更新历史

- 界面顶栏一直显示当前版本号（例如 `v1.0.0-rc.2`），点一下就能打开「更新历史」。
- 更新历史按版本倒序列出每个版本改了什么；当前版本带「当前版本」标记并默认展开，其他版本折叠着，也可以用键盘操作。
- 这些说明随程序一起打包，打开不需要联网。
- 顺便说清楚「升级」这件事：**本程序不会自动更新**——不联网检查新版本、不自动下载、也不会偷偷替换自己。想升级就用新版 exe 替换旧 exe，你的设置与备份都在数据目录里，替换后照旧可用。
- 状态栏里的「版本」是 nginx 自己的版本；顶栏这个是你正在用的 nginx-manager 版本，两者不是一回事。

### 暗夜主题看久了不那么累

- 之前深色主题的白字偏亮、对比偏强，长时间盯着容易疲劳；这一版把文字亮度调柔了一档，正文、次级文字和状态色的层次更自然，但依然清晰可读。
- 亮色主题也同步微调，颜色更柔和，同样保持清晰。
- 8 套主题（4 配色 × 日夜）都按同一套标准逐项核对过。

### 请你重点试试

- 顶栏的版本号是否和你下载的 exe 对得上；点开「更新历史」能不能正常看到各版本说明。
- 上一版的重点项也请一并走一遍：日志自动跟随、暂停后阅读位置是否不被顶走；编辑器行号与撤销重做（Ctrl/Cmd+Z、Ctrl+Y）；只用键盘能否完成常用操作；代理目标切换与负载均衡改动后 nginx 是否正常重载。
- 覆盖安装：用新 exe 替换旧 exe 后，原来的设置与备份是否照旧可用。

反馈问题时请带上顶栏显示的版本号，方便定位。
