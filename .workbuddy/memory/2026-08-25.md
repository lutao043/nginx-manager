## nginx-manager 多实例 + 移除强杀命令修复（用户报「重载会产生很多 nginx 实例，停止使用强杀命令」）
- **根因1（多实例）**：`detect_process()` Windows 分支原要求 `len(procs) == 1`（恰好 1 个 nginx.exe）才认作运行中。当 PowerShell 熔断降级到 tasklist（多实例共存、无 exePath）时，旧逻辑返回 `running: False` → `restart()` 跳过 stop 直接 `start()` → 每次重载多开一个实例，越积越多。
  - 修复：`if running_proc is None and procs: running_proc = procs[0]`（只要有 nginx.exe 即视为运行中）。
- **根因2（强杀命令）**：`stop()` 原在 `-s quit` 优雅退出失败后升级调用 `-s stop`（强制停止=强杀），易误伤其他 nginx 进程且丢失在途请求。
  - 修复：`stop()` 仅保留 `-s quit`；优雅失败返回错误让用户决定，不再升级为 `-s stop`。
- **加固**：`restart()` 改为无条件先发 `-s quit` 再 `start()`，避免漏停旧实例。
- **验证**：写 `/tmp/verify_nginxctl.py`（monkeypatch `WIN=True` + 假多实例进程列表 + 拦截 `_run`）跑 4 项断言：(a) 多实例 tasklist 检测→running=True (b) stop 仅 -s quit 无 -s stop (c) restart 首条命令必为 -s quit (d) 全程无 -s stop 调用。**全部 PASS**；`py_compile nginxctl.py` 通过。
