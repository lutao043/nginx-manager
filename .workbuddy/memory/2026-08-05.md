# 2026-08-05 nginx-manager 工作日志

## v0.1 附件热修复：tkinter 缺失

- 用户下载 v0.1 exe 后报 `No module named 'tkinter'`
- 根因：PyInstaller 静态分析不会把标准库 tkinter 的底层 `_tkinter.pyd` 和 tcl/tk DLL 自动打入 onefile exe
- 修复：spec 改用 `collect_submodules('tkinter')` 强制收集所有子模块（替换原本的 `hiddenimports=["tkinter"]`）
- 本机验证：启动 exe → 8310 端口正常 LISTENING，无 tkinter 报错
- 重新打包后用 Gitea API 覆盖 v0.1 release 附件（`POST /releases/11/assets`），Release 描述追加更新说明
- 提交 `f8c69e3` 推送成功

## v0.1.1：tkinter 缺失的真正根因

- 用户反映 v0.1 修复后仍报 tkinter 错
- 真正根因：托管 Python 3.13.12 **根本没装 tkinter 标准库**（pip 装不了，必须 Python 安装时勾选 tcl/tk）
  - `collect_submodules('tkinter')` 只能收子模块名，找不到 _tkinter.pyd
  - 之前"8310 LISTENING"是 settings 已有、走快路径未触发 `import tkinter`
  - 用户首次启动必走 `pick_nginx_via_dialog()` → import tkinter 失败
- Gitea Release API 上传同名附件是**追加而非覆盖**，v0.1 实际有 2 个 8.2MB 的失效附件
- 修复：
  - 改用系统 Python 3.14 打包（自带 _tkinter.pyd / tcl86t.dll / tk86t.dll）
  - 新 exe 11.7MB（v0.1 是 8.2MB），已扫描验证包含所有 tkinter 二进制
  - 删除 v0.1 两个旧附件，新建 v0.1.1 release
  - build.py 加 tkinter 存在性检测（缺则直接退出 + 提示用哪条 Python 重跑）
  - 沙箱 shim 兼容：清理用 rename 而非 rmtree；patch os.remove 绕过 _safe_remove

## 教训

- **打包 Python GUI 程序必须用带 tcl/tk 的 Python**——不是 collect_submodules 能解决的
- **PyInstaller 静态分析只能看到显式 import 的模块名**；标准库 tkinter 缺 _tkinter.pyd 时 collect_submodules 也不灵
- **Gitea Release API 上传同名附件是追加**，要先 DELETE 再上传（或用新 release）
- **OneFile exe 本地启动测试要看真实路径**——settings 已有会跳过部分代码，掩盖 bug

## 保存按钮无反应 bug（提交 416154c）

- 用户报告：配置文件页点「保存」没反应
- 根因：ui.js `confirmChoice`（保存三选一确认框）**缺少 `mask.hidden = false`**
  ——弹窗 DOM 建好但永远不可见，与 confirmDialog 对比缺一行。保存按钮点击后弹窗弹不出，
  用户无法点「保存并备份/仅保存」，表现就是"没反应"
- 排查手段：Edge headless + CDP（--remote-debugging-port）写 node 脚本模拟点击，
  逐步打印弹窗状态（500ms/1300ms），复现 hidden:true → 修复后 hidden:false + 保存成功
- 教训：改弹窗逻辑后一定要验证"弹窗真的可见"；对比同文件相似函数找差异
- 顺带清理：打包遗留 build_prev/dist_prev 目录已删

## 代理管理页加载失败 bug（提交 7b0d24c）

- 用户报告：代理管理页显示「加载失败：Cannot set properties of null (setting 'textContent')」
- 根因：loadProxies 残留 `$("#proxySearchCount").textContent = ""`——实现时实际用的是
  `#proxyCount`，残留的旧 id 不存在 → $() 返回 null → 抛 TypeError → catch 显示加载失败
- 修复：删除残留行；CDP 验证 97 代理加载/搜索过滤/清除全通过
- 教训：改代码时注意删除旧的元素引用；$() 对不存在元素返回 null 不报错，用前要判空
