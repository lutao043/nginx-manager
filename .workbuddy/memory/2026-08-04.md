## nginx 轻量网页管理端 — 方案敲定（待开工）

用户需求：Windows/macOS/Linux 轻量网页端管理 nginx，可改配置文件、重启服务。

### 已敲定的决策
- 后端：Python 标准库（http.server + subprocess），零第三方依赖
- 前端：原生 HTML/CSS/JS，零构建零框架，护眼绿主题（用户偏好）
- 功能档位：标准版 —— 配置文件树（解析 include）+ 原始文本编辑 + `nginx -t` 校验 + 启停/重载 + 编辑前自动备份与回滚 + 错误日志查看
- 安全：仅绑定 127.0.0.1，无登录/token
- **不搞路径自动探测**：首次使用由用户通过文件管理器对话框指定 nginx 程序路径（tkinter filedialog），保存到 settings
- **支持打包**：PyInstaller 单文件 exe，运行时数据（settings/backups）放用户目录而非程序目录，避免 onefile 临时目录不可写
- **端口启动时指定**：`--port` 参数，未指定用默认（待定 8080）
- 跨平台：Windows（nginx.exe -s reload、start 分离进程）、macOS/Linux（nginx -s reload 直接执行）

## 代理管理面板（2026-08-04 晚）
用户核心场景：日常管理大量反向代理，主要切换目标地址（如 /xxxxWeb、/xxxxxService）。
- 方案决策：直接改 nginx.conf（不做独立文件）、多备选一键切换、标准样板（3 行 proxy_set_header）
- **核心机制**：一个 location 块内激活 proxy_pass 不注释、备选 proxy_pass 加 # 注释，
  切换 = 互换注释状态；nginx 原生语法兼容，配置人类可读
- 新增 backend/proxymgr.py：行级解析 location+proxy_pass（正则匹配，跳过注释行/静态资源），
  add/switch/update_targets/remove 全整文件文本替换，失败可 restore 原文
- server.py 新增 /api/proxies 系列（GET 列表 / POST 添加 / PUT switch、targets / DELETE 删除），
  修改前自动备份 nginx.conf
- 前端新增「代理管理」页签（配置文件/代理管理双页签）：列表（路径+当前目标+备选下拉）、
  添加弹窗、编辑备选弹窗（radio 勾选激活）、删除
- 关键修复：proxymgr 各操作前需 _refresh()（从内存 content 重解析 blocks），
  否则 add 后找不到新代理（KeyError 教训）
- 已实测全链路：添加→更新备选→切换→删除，nginx -t 全通过
- 提交 d85b983 推送成功
